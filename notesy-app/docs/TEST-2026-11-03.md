# Uji lapangan Notesy — 3 Nov 2026

## 1. MacBook Air (macOS 26.2, Chrome 156) saat rapat Zoom desktop

Build: ekstensi Chrome `dist-ext` (MV3), dimuat sebagai unpacked di profil Chrome terpisah.

| Aspek | Hasil |
| --- | --- |
| Rekam layar + audio | Gagal: `NotReadableError: Could not start video source`. Chrome belum diberi izin macOS "Perekaman Layar & Audio Sistem". |
| Rekam mikrofon | Lolos. 5:12 tanpa putus, tetap jalan saat jendela diperkecil. Zoom dan Notesy memakai mikrofon bersamaan tanpa konflik. |
| Ukuran audio | mic 1,2 MB, mix 2,5 MB (sekitar 3,8 KB/detik dan 8 KB/detik). |
| Sumber daya | RAM seluruh proses Chrome uji sekitar 1,0–1,1 GB, stabil (tidak bocor). CPU 40–70% satu inti selama merekam. |
| Unduh model | Whisper Small (sekitar 590 MB file ONNX) sekitar 6 menit saat bandwidth dipakai Zoom; sekali saja, setelah itu dimuat dari cache dalam kurang dari 10 detik. |
| Transkripsi | Audio 5:12 selesai dalam sekitar 2:40 (WebGPU, 0,5× durasi). 72 segmen. Isi terbaca; salah dengar pada istilah teknis ("sumup detector", "hindran"). |
| Ringkasan Cursor | Sekitar 100 detik. Judul otomatis "Pencegahan dan Proteksi Kebakaran Komprehensif". Istilah dibetulkan (smoke/flame detector, hydrant, APAR). Tidak mengarang tugas untuk Izza. |
| Pemulihan | Proses yang terputus karena ekstensi dimuat ulang berubah menjadi status error "Proses ulang", dan klik itu memprosesnya sampai selesai. |

### Bug ditemukan dan diperbaiki
1. **Kritis — transkripsi macet di ekstensi.** transformers.js membungkus file ORT lokal menjadi skrip `blob:` (fitur `useWasmCache`). CSP ekstensi MV3 melarang `blob:`, sehingga worker diam selamanya di "Mengunduh model 100%". Diperbaiki dengan `env.useWasmCache = false` di `src/lib/stt/worker.ts`. Bug ini juga akan mengenai laptop kantor Windows.
2. **ID model tidak dikenal** membuat transkripsi gagal dengan error Hugging Face. Sekarang otomatis kembali ke Whisper Small (`src/lib/stt/index.ts`).

### Temuan yang belum diperbaiki
- Mode "Mikrofon saja" memberi label semua ucapan "Saya", padahal yang bicara adalah pemateri di Zoom yang keluar dari speaker. Ringkasan tetap benar, tetapi label transkrip menyesatkan.
- CPU 40–70% saat merekam cukup tinggi untuk laptop kantor. Kemungkinan dari pembaruan meter 120 ms; perlu diturunkan saat jendela tidak terlihat.

## 2. POCO X8 Pro Max (Android 16, HyperOS)

APK terpasang dan pengaturan terisi. Harness menunggu 10 menit, tetapi Zoom di HP tidak pernah memakai mikrofon (rapat berjalan di MacBook), sehingga uji 5 menit belum dijalankan. APK terbaru dengan perbaikan worker sudah dibuat di `android/app/build/outputs/apk/debug/app-debug.apk` dan belum terpasang karena adb terputus.

## 3. Versi web di Vercel (notesy-three.vercel.app) saat rapat Zoom, masuk dengan kode akses

| Aspek | Hasil |
| --- | --- |
| Proxy Cursor | Kode akses benar terhubung ke akun Cursor; kode salah ditolak (401); tanpa kode ditolak; path di luar `/v1/` ditolak. |
| Rekam mikrofon | 5:06 tanpa putus. CPU turun ke 8–25% saat tab tidak terlihat. RAM Chrome uji sekitar 800–870 MB. |
| Transkripsi | 64 segmen, sekitar 2 menit setelah model termuat. Unduhan model pertama sekitar 8 menit (jaringan dipakai Zoom). |
| Ringkasan | Judul "Sertifikasi Grounding dan Jadwal Lanjutan". Buat ulang ringkasan selesai dalam 50 detik. |
| Deploy otomatis | Push ke GitHub `main` ter-deploy ke production dalam sekitar 15 detik. |

Bug yang ditemukan dan diperbaiki: pada rekaman mikrofon saja, ringkasan menyebut "pembicara hanya Saya, yaitu Izza" padahal suara berasal dari peserta Zoom lewat speaker. Prompt sekarang memberi tahu AI bahwa label tidak menunjukkan pembicara; hasil ulang menulis "peserta".

## 4. Langkah berikut
1. Beri izin di Mac: Pengaturan Sistem → Privasi & Keamanan → Perekaman Layar & Audio Sistem → aktifkan Google Chrome → Keluar & Buka Ulang. Lalu uji ulang mode layar (slide otomatis).
2. Zoom desktop di Mac: audio peserta hanya terekam lewat mikrofon (speaker, bukan headphone). Untuk audio bersih, buka Zoom di tab Chrome lalu bagikan tab dengan "Bagikan audio tab".
3. Ulangi uji HP saat ada rapat Zoom di HP.
